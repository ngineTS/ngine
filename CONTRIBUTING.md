# Contributing to ngine-database

Thank you for considering contributing to ngine! We welcome contributions from everyone. Below are some guidelines to help you get started.

## How to Contribute

This database repository contains the initial script of the application. To push change you must create a pull request for the addition of a new file containing the database script of the change. The file name format is `DD-MM-YYY_your_change`. If this change come with backend and frontend code changes, the Pull Request link of these two repositories must be menitoned in the comment of the commit.

**Create a Pull Request**: Open a pull request to the main repository.

## Code of Conduct

Please note that this project is released with a [Contributor Code of Conduct](CODE_OF_CONDUCT.md). By participating in this project you agree to abide by its terms.
