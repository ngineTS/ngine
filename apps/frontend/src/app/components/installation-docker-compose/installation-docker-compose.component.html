Docker Compose

Get Ngine running with Docker Compose by following the below steps.

Prerequisite: Docker must be installed and running on your machine.

  1. 1
    Clone the repository

    Clone the Ngine repository, then open a terminal in its root folder:

    git clone https://github.com/ngineTS/ngine.git
  2. 2
    Configure your environment

    Create a .env file in the repository root. The easiest way is to copy .env.example and rename the copy to .env.

    Open .env and replace the example values with your own configuration.

  3. 3
    Start Ngine

    Run Docker Compose from the repository root:

    docker compose up
  4. 4
    Wait for the services to start

    The first start may take a few minutes while Docker builds and downloads the required images. When it is ready, open http://localhost:4200.
