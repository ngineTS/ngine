Local Installation

Run Ngine directly on your machine for local development.

Prerequisites:
  • Node.js version 20 or later
  • PostgreSQL, or another supported database, installed and running
  1. 1
    Clone the repository

    Clone the Ngine repository, then open a terminal in its root folder:

    git clone https://github.com/ngineTS/ngine.git
  2. 2
    Configure your environment

    In the repository root, copy .env.example and name the copy .env.

    Open .env and replace the example values with your database details and other required configuration.

  3. 3
    Install dependencies

    From the repository root, install the dependencies for both apps:

    npm install
  4. 4
    Start the application

    Start the backend and frontend from the repository root:

    npm start
  5. 5
    Wait for the app to load

    When the servers have started, open the frontend at http://localhost:4200.
