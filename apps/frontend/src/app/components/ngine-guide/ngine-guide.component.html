A QUICK TOUR

From blank page to brilliant app.

The idea is simple: design your page, add features from your library, and publish when you’re ready. Here’s how to make the most of Ngine.

  1. 01

    Set your app’s default style

    Start with the look and feel you want across your page. Set defaults for container layout, container styling, and typography. New components will pick up these styles automatically.

  2. 02

    Add components to the page

    Choose Add component to open the component picker and select a feature from your library. You can also add common navigation elements directly:

    ↔Horizontal navigationA classic top navigation bar
    ☷Vertical navigationA handy navigation tree
    Explore the feature library ↗
  3. 03

    Style each component your way

    Every component inherits the default style from step 1. Want something different? Use the style buttons in the top-right corner to customize a component independently.

  4. 04

    Publish your changes

    When everything looks good, open the publish interface to publish your changes. Not quite there yet? Cancel to leave your current version as it is.

  5. 05

    Develop and register a new component

    When your next business feature isn’t in the library yet, develop it in your codebase. Add the Ngine schematic, then generate a Ngine component:

    01ng add ngine-component
    02ng generate base-component <name>

    Build your feature with Angular on the frontend and NestJS on the backend. The Ngine components contains properties like canAdd, canEdit and canDelete to implement permission control directly in the code without having to code it yourself.

    Once it's ready, click on New component type in the global toobar and add its <name> reference to the library.

    ↻ Your feature is now part of the library and can be resued everywhere!
  6. 06

    Admin interface

    The admin interface comes with useful tools to help you run your application. You can customize it like the rest of the app and add as many features as you want!

    User rolesCreate roles and manage access to app sections and components.
    AnalyticsKeep an eye on your application's key KPIs.
    File managementManage the files uploaded to your application.
    Banner managementCreate and schedule important messages for your users.
